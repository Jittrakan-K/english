# Speakeasy

พูดภาษาอังกฤษให้คล่อง ตั้งแต่ศูนย์ (ชื่อเดิม: สวนภาษา)

เว็บเรียนภาษาอังกฤษสำหรับคนไทย ตั้งแต่ไม่รู้อะไรเลยจนพูดได้คล่อง เป็น HTML5 ล้วน ไม่ต้อง build ไม่ต้องติดตั้งอะไร เปิดบน GitHub Pages ได้ทันที

## มีอะไรบ้าง

- **เส้นทาง (Roadmap)**: 7 ขั้นตาม CEFR (Pre-A1, A1, A2, B1, B2, C1, C2) ขั้นละ 8 บท แต่ละขั้นเป็นเหมือนสไลด์หนึ่งแผ่น บทเรียนเป็นวงกลมมีหมายเลขเรียงบนเส้น เส้นจะเติมสีตามบทที่ผ่าน เห็นทันทีว่าเรียนถึงไหน
- **บทเรียน 56 บท**: หลักไวยากรณ์อธิบายเป็นภาษาไทย คำศัพท์ 561 คำ ประโยคตัวอย่าง 280 ประโยค ทุกคำแตะฟังเสียงได้
- **ข้อผิดที่คนไทยพบบ่อย 168 ข้อ**: ทุกบทมีตัวอย่างประโยคผิดเทียบประโยคถูกพร้อมเหตุผล (เช่น She beautiful, Did you went, I'm agree) และกลายเป็นแบบฝึก "ประโยคไหนถูก"
- **แบบฝึก 11 แบบ**: เลือกความหมาย, แปลไทยเป็นอังกฤษ, ฟังแล้วเลือก, สะกดคำ, จับคู่คำกับความหมาย, เติมคำในช่องว่าง, เลือกประโยคที่ถูก, เรียงคำเป็นประโยค, ฟังแล้วเรียงคำ, ฟังแล้วพิมพ์ทั้งประโยค (dictation), แยกคู่เสียงที่คนไทยมักสับสน และพูดออกเสียงให้ระบบตรวจ ข้อที่ตอบผิดจะวนกลับมาให้ลองอีกครั้ง
- **ฝึกรวมจุดที่ยังไม่แม่น**: ชุดฝึกผสมจากบทที่เรียนแล้ว เลือกคำที่ใกล้ลืมและบทที่คะแนนต่ำมาก่อน คำที่ตอบผิดจะถูกส่งกลับไปทวนวันนั้นทันที
- **ด่านสอบท้ายขั้น**: ผ่าน 75% ขั้นถัดไปจะเปิด คนที่เคยเรียนมาแล้วสอบข้ามขั้นได้เลย
- **ทวนคำศัพท์ (SRS)**: คำจากบทที่ผ่านแล้วเข้าระบบทวนตามรอบความจำ คำที่จำได้จะเว้นระยะนานขึ้น คำที่ลืมจะกลับมาเร็วขึ้น
- **ห้องฝึกพูด**: พูดตามประโยค (ระบบไฮไลต์คำที่ได้ยินถูกและพลาด), ตอบคำถามแบบเปิด และบทสนทนาจำลอง 14 สถานการณ์ (สั่งกาแฟ, เช็กอินโรงแรม, สัมภาษณ์งาน, ต่อรองราคา, ถกเถียง) เล่นได้ทั้งแบบเลือกประโยค แบบพูดเองไม่มีตัวเลือก และสลับไปเล่นอีกบท
- **คลังศัพท์ 2,540 คำ** (รวมคำในบทเรียนแล้วกว่า 3,000 คำ): คำที่ใช้บ่อยที่สุดระดับ A1 ถึง C1 แบ่งเป็น 127 ชุดตามหัวข้อ ชุดละ 20 คำ พร้อมชนิดคำ เสียงอ่าน แบบฝึก 4 แบบต่อชุด และเข้าคิวทวน (SRS) อัตโนมัติ ค้นหาได้ทั้งไทยและอังกฤษ ไฟล์อยู่ที่ `js/vocab-*.js` เพิ่มชุดใหม่ได้โดยไม่ต้องแก้โค้ด
- **คำจากบทเรียน**: ค้นหาคำ กรองตามระดับ ดูสถานะความจำ
- **สถิติ**: วันต่อเนื่อง, แต้ม, ปฏิทิน 16 สัปดาห์, ความคืบหน้าทีละขั้น, ตั้งเป้ารายวัน, เลือกเสียงผู้อ่านและความเร็ว
- **บัญชีผู้ใช้**: สมัครด้วย Username กับรหัสผ่าน (อย่างน้อย 6 ตัว) ที่ตั้งเองในเว็บ ไม่ต้องใช้อีเมล ใส่ Username กับรหัสผ่านเมื่อไรความคืบหน้าของบัญชีนั้นก็ขึ้นมา เชื่อม Firebase แล้วเข้าได้จากทุกเครื่อง
- **สำรองข้อมูล**: ดาวน์โหลดความคืบหน้าเป็นไฟล์แล้วโหลดกลับในเครื่องอื่นได้

## บัญชีผู้ใช้และ Firebase

ปุ่มบัญชีอยู่มุมขวาบน (หน้า `#/account`) ใช้ได้สองแบบ

- **ยังไม่เชื่อม Firebase**: บัญชีอยู่ในเบราว์เซอร์เครื่องนั้นเท่านั้น เหมาะกับหลายคนใช้เครื่องเดียวกัน รหัสผ่านเก็บเป็นค่า hash แต่คนที่เปิดเครื่องได้ก็ยังเข้าถึงข้อมูลในเบราว์เซอร์ได้ จึงเป็นการแยกข้อมูล ไม่ใช่การล็อกที่ปลอดภัย
- **เชื่อม Firebase แล้ว**: Username กับรหัสผ่านตรวจด้วย Firebase Authentication และความคืบหน้าเก็บใน Firestore เข้าจากเครื่องไหนก็เจอข้อมูลเดิม ถ้าเรียนสองเครื่องพร้อมกัน ระบบจะรวมให้ ไม่ทำให้บทที่ผ่านแล้วหรือคะแนนที่ดีกว่าหายไป บัญชีที่สร้างไว้ก่อนเชื่อม Firebase ให้กด "สร้างบัญชีใหม่" ด้วย Username กับรหัสผ่านเดิม ความคืบหน้าจะย้ายขึ้นคลาวด์ให้เอง

วิธีเชื่อม Firebase (ใช้แพ็กเกจฟรี Spark ได้)

1. เข้า [console.firebase.google.com](https://console.firebase.google.com) กด **Create a project** ตั้งชื่ออะไรก็ได้ (ไม่ต้องเปิด Google Analytics)
2. เมนู **Build > Authentication** กด **Get started** แท็บ **Sign-in method** เปิด **Email/Password** แล้วกด Save (ไม่ต้องเปิด Email link) ตัวเลือกนี้เป็นแค่กลไกตรวจรหัสผ่านของ Firebase ผู้ใช้ในเว็บไม่ต้องกรอกหรือมีอีเมล
3. เมนู **Build > Firestore Database** กด **Create database** เลือกตำแหน่ง เช่น `asia-southeast1` แล้วเลือก **production mode**
4. ในหน้า Firestore แท็บ **Rules** วางเนื้อหาจากไฟล์ `firestore.rules` ใน repo นี้ แล้วกด **Publish**
5. กดรูปเฟือง **Project settings** เลื่อนลงไปที่ **Your apps** กดไอคอน `</>` (Web) ตั้งชื่อแอป แล้วกด Register (ไม่ต้องเปิด Hosting)
6. คัดลอกค่า `apiKey` กับ `projectId` จากโค้ดที่ Firebase แสดง ไปใส่ในไฟล์ `js/cloud-config.js` แล้ว commit ขึ้น GitHub

`apiKey` ของเว็บแอป Firebase เป็นค่าที่เปิดเผยได้ตามปกติ สิ่งที่กันไม่ให้คนอื่นอ่านข้อมูลคือกฎใน `firestore.rules` ซึ่งให้แต่ละบัญชีอ่านและเขียนได้เฉพาะข้อมูลของตัวเอง

เบื้องหลัง: Firebase เก็บผู้ใช้เป็นคู่ "ตัวระบุ + รหัสผ่าน" เว็บจึงแปลง Username เป็นรหัสประจำตัวแบบ hash เช่น `u3f9a...@speakeasy.example.com` ให้เองโดยอัตโนมัติ ผู้ใช้ไม่เคยเห็นหรือพิมพ์ค่านี้ `example.com` เป็นโดเมนสงวนที่ไม่มีใครรับอีเมลได้ จึงไม่มีอีเมลส่งออกไปไหน ในหน้า Authentication ของ Firebase คอลัมน์ Identifier จะเห็นค่านี้แทน Username ส่วน Username จริงอยู่ในช่อง `name` ของเอกสารใน Firestore (`users/{UID}`)

รหัสผ่านที่ลืมกู้คืนไม่ได้ ต้องเข้าไปลบผู้ใช้นั้นในหน้า Authentication แล้วสมัครใหม่

## แก้หรือเพิ่มบทเรียน

เนื้อหาอยู่ใน `js/data.js` (หลักสูตรหลัก) และ `js/data-more.js` (บทที่เพิ่มต่อท้ายแต่ละขั้น ข้อผิดที่พบบ่อย และบทสนทนาจำลอง) ระบบรวมสองไฟล์ให้อัตโนมัติ แต่ละบทมีโครงสร้างแบบนี้:

```js
{
  id: "s0l2", title: "ทักทาย", en: "Hello", head: "H",
  goal: "สิ่งที่ผู้เรียนจะทำได้",
  notes: ["หลักไวยากรณ์ ใช้ <b>ตัวหนา</b> ได้"],
  words: [["hello", "สวัสดี"]],
  sents: [["Hello, I am Nok.", "สวัสดี ฉันชื่อนก"]],
  pairs: [["ship", "sheep"]],  // ไม่ใส่ก็ได้
  fix: [["She beautiful.", "She is beautiful.", "เหตุผลภาษาไทย"]]  // ไม่ใส่ก็ได้
}
```

แบบฝึกหัดสร้างจาก `words`, `sents`, `pairs` และ `fix` อัตโนมัติ ไม่ต้องเขียนเพิ่ม

## โครงไฟล์

```
index.html     โครงหน้าและเมนู
app.css        หน้าตาทั้งหมด (นำเข้า tokens.css และ base.css)
tokens.css     สี ฟอนต์ ระยะห่าง
base.css       กติกาพื้นฐาน
js/data.js     หลักสูตรหลัก
js/data-more.js  บทเพิ่มเติม ข้อผิดที่พบบ่อย บทสนทนาจำลอง
js/app.js      ตัวแอป: เส้นทาง บทเรียน แบบฝึก ทวนคำ ฝึกพูด สถิติ บัญชี
js/account.js  ระบบบัญชี: ในเบราว์เซอร์ หรือ Firebase ผ่าน REST
js/cloud-config.js  ค่า apiKey และ projectId ของ Firebase
firestore.rules     กฎความปลอดภัยของ Firestore
favicon.svg    โลโก้: ฟองคำพูดตัด S (ไอคอนแท็บ)
```

## หน้าตาและโลโก้

- สไตล์สติกเกอร์ (Hallmark Sticker theme): การ์ดมีขอบไดคัตสีขาวหนา เงาแข็งไม่เบลอ เอียงนิด ๆ สลับซ้ายขวา เส้นทางเรียนเป็นแผ่นสติกเกอร์ บทที่ผ่านแล้วคือสติกเกอร์ที่ติดลงไปแล้ว
- สีใช้ชุดเดิมของเว็บ: เหลืองครีม ฟ้าลาเวนเดอร์ ชมพู ฟ้า มิ้นต์ ปุ่มหลักสีเขียวทีล
- ฟอนต์: Bowlby One SC (หัวข้ออังกฤษ) + Sofia Sans (เนื้อหา) และ Kanit สำหรับภาษาไทย (Google Fonts)
- โลโก้: ฟองคำพูดทรงเรขาคณิตสีดำ เจาะช่องว่างเป็นตัว S (Speakeasy) แบบมินิมอล ไฟล์ `favicon.svg` (เปลี่ยนเป็นสีอ่อนเองเมื่อแท็บเป็นธีมมืด) และ `apple-touch-icon.png`
- สีทั้งหมดอยู่ใน `tokens.css`
